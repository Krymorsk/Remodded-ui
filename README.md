# FORM — Fitness OS

Offline-first personal fitness tracker. The live app is the React build in this workspace; this folder keeps the original vanilla prototype as reference.

## What it does
- Modes: Normal / Bulk / Comeback (history is never deleted)
- Auto or manual training, with rest days and deloads when recovery is low
- Live workout session with rest timer and last-time comparison
- Auto-detected PRs from logged sets
- Nutrition: calories, protein, carbs, fat, water
- Weight, BMI, measurements, sleep, steps
- kg/lb and cm/in, light/dark/system
- Export / import JSON backup (localStorage)

## Run
The preview app starts automatically. Data stays in the browser.
